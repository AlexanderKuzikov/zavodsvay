<h1 align="center">zavodsvay</h1>
<p align="center">Legacy-версия сайта завода свайных фундаментов «Гефест»</p>

---

Промежуточная итерация сайта zavodsvay.ru (PHP file-router + Node.js утилиты + Sharp). Заменён на [Zavodsvay-Static](https://github.com/AlexanderKuzikov/Zavodsvay-Static).

- **PHP file-router** — index.php, layouts/, pages/, partials/
- **Node.js утилиты** — cleaner.js, collect-content.js, init-structure.js
- **Sharp** — обработка изображений (единственная npm-зависимость)

## Быстрый старт

```bash
git clone https://github.com/AlexanderKuzikov/zavodsvay.git
```

Проект архивирован. Актуальная версия — [Zavodsvay-Static](https://github.com/AlexanderKuzikov/Zavodsvay-Static).
